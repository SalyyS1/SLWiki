First deployment

Install without replacing server choices

OmniEnchant copies missing defaults and adds missing YAML keys during migration. Existing values and customized files remain untouched.

1

Install dependencies

Run Java 21 with Paper or Folia 1.21+, MMOItems, and MythicLib. Add MythicMobs when custom skill dispatch is required.

2

Deploy the JAR

Place OmniEnchant.jar in plugins/, start once, then edit generated files under plugins/OmniEnchant/.

3

Add MMOItems slots

Define enchantslots on the MMOItems template and place #enchantslots# in its lore-format.yml.

4

Validate a real item

Use /sle give, drag the book onto an item, inspect detailed lore, then test member compact mode with /sle compact.

Known-good baseline

MMOItems virtual enchant slots

Each list entry is one logical slot. Detailed mode keeps descriptions beneath filled slots; compact mode condenses them only after the player enables it.
